# DeepSeek Harness 实操手册

**从视频到本机：一台 Windows 机器上的 DSH 落地记录（v0.2.2-rc.1）**

这不是逐字稿，也不是官方文档的翻译。它是照着一条 50 分钟的视频教程，把每一步在一台真实机器上跑一遍之后留下的笔记：核对版本、读插件树、开子代理、跑工作流、进 plan mode、装技能包，撞到坑就把坑一起记下来。

## 适合谁

- 装了 DSH 但不知道从哪下手的人：第 2 到 4 页可以直接当入门走一遍。
- 改了配置「却没生效」的人：[功能开关](06-switches.md)这一页大概能解释你遇到的事。
- 想看清 DSH 内部形状的人：[技术概念](01-concepts.md)和[插件实战](05-plugins.md)是给这个写的。

## 不适合谁

- 想要 API 参考手册的人：这里只有实操路径，接口细节请查官方文档。
- 想要视频讲解稿的人：视频没有公开字幕，本书不提供转写。
